# Маскот и брендовые файлы

Интерфейс уже умеет показывать настоящего маскота. Пока PNG-файлов нет,
страницы подставляют `crest.svg` — осознанную запасную эмблему, а не битую
картинку. Как только файл появится под нужным именем, он подхватится сам,
править код не нужно.

## Какие файлы нужны

| Файл | Где виден | Что на нём |
|---|---|---|
| `mascot-calm.png` | главный экран VPN, активная подписка | спокойный тюлень со щитом |
| `mascot-helping.png` | онбординг, шаги установки | тюлень показывает путь: фонарь или карта |
| `mascot-success.png` | «Готово — сервер видит подключение» | тюлень радуется, золотая звезда |
| `mascot-error.png` | подписка закончилась, ошибка | тюлень осторожно предупреждает |
| `mascot-empty.png` | пустое состояние, приглашение по коду | тюлень с подзорной трубой или билетом |
| `avatar.png` | шапка всех страниц | текущая аватарка бота, обрезанная в квадрат |

Формат: **PNG с прозрачным фоном, 512×512** (квадрат). Браузер сам уменьшит.
`avatar.png` можно просто взять из аватарки бота — обрезать в квадрат и сохранить.

Класть сюда: `web/connect/assets/`.

## Важное про стиль

Референсы, которые сгенерировал UI-kit, взяли не того зверя. Единственный
источник правды — **настоящая аватарка бота**: серо-белый тюлень с крупными
тёмными глазами, тёмно-синяя остроконечная шляпа со звёздами, золотая вышивка,
синий плащ, щит с золотым замком, циановые линии созвездий.

К каждому запросу **обязательно прикладывать саму аватарку** как character
reference. Без неё генератор рисует другого зверя.

## Промпты для ChatGPT

Общая часть — подставлять в начало каждого запроса:

```text
К этому сообщению приложена настоящая аватарка маскота Fodder VPN.
Используй её как строгий character reference: тот же серо-белый тюлень,
та же форма морды и глаз, та же тёмно-синяя остроконечная шляпа со звёздами,
та же золотая вышивка и синий плащ. Не меняй вид животного, лицо, шляпу
и характер. Не делай другого зверя, не делай 3D-clay, не делай kawaii-стикер.

Нарисуй аккуратную плоскую векторную версию этого же персонажа: чистые формы,
мягкие контуры, минимум мелких деталей, читается в 96 px. Палитра строго:
night navy #071827, raised navy #102A3B, warm parchment #F5F0E5,
seal cream #E9E1D2, connection cyan #28C7E4, magic gold #E3AE43,
botanical teal #3B7C72, danger #D65A5A.

Фон полностью прозрачный. Квадрат 512×512. Персонаж вписан в кадр с небольшим
запасом по краям. Без текста, без рамки, без подписи, без фотографической
текстуры ткани и без AI-шума.
```

Дальше — по одному запросу на состояние:

**`mascot-calm.png`**
```text
Состояние «спокоен». Тюлень стоит ровно и держит щит с золотым замком.
Взгляд прямой и доброжелательный. Никакого действия, никакой эмоции сверх меры —
это фоновый персонаж на главном экране, он не должен перетягивать внимание
с текста о подписке.
```

**`mascot-helping.png`**
```text
Состояние «помогает». Тюлень держит небольшой фонарь или свёрнутую карту и
показывает свободной ластой направление. Поза приглашающая, корпус слегка
развёрнут вперёд. Он проводник в установке приложения, а не волшебник в бою.
```

**`mascot-success.png`**
```text
Состояние «успех». Тюлень довольный, над ним или в ласте одна золотая звезда
#E3AE43. Лёгкое циановое свечение #28C7E4 вокруг щита. Без конфетти,
без фейерверка, без восклицательных знаков — тихая радость, а не праздник.
```

**`mascot-error.png`**
```text
Состояние «осторожная ошибка». Тюлень слегка обеспокоен и поднял ласту в жесте
«подождите». Рядом маленький круглый знак внимания цвета #D65A5A.
Он не напуган и не виноват: подписка просто закончилась, всё поправимо.
Не рисуй слёзы, не рисуй грусть.
```

**`mascot-empty.png`**
```text
Состояние «пока пусто». Тюлень смотрит вдаль через маленькую подзорную трубу,
рядом ничего нет. Спокойное ожидание, а не растерянность. Используется там,
где у человека ещё нет ни одного профиля.
```

## Иконка приложения — отдельный запрос

```text
Сделай не экран, а малый набор брендовых файлов Fodder VPN на основе
приложенной настоящей аватарки: круглая аватарка Telegram, квадратная иконка
приложения 1024×1024 и favicon 32×32.

Сохрани морду серо-белого тюленя, тёмно-синюю шляпу со звёздами и маленький щит
с замком. Упрости до чистой плоской эмблемы из 3–5 крупных форм в палитре
navy / cyan / gold, с сильным силуэтом и хорошей читаемостью в 32 px.
Без текста внутри иконки, без мелких созвездий, без фотографической ткани.
Категорически не использовать белую кривую на синем квадрате, дежурный щит,
глобус или букву F.
```

## Проверка результата

Перед тем как класть файл в репозиторий:

1. Открыть на белом и на тёмном фоне — прозрачность не должна давать белой каймы.
2. Уменьшить до 96 px и до 44 px — если превращается в кашу, деталей слишком много.
3. Сравнить с аватаркой рядом — это должен быть очевидно тот же персонаж.
