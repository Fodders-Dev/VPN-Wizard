Выберите свой маршрут

Проверяем работу VPN на серверах. Доступность у вашего оператора может отличаться.

    Три шага — и вы на связи

    1. Установите AmneziaWG для вашего устройства по ссылкам ниже.
    2. Скачайте профиль сервера выше. Импортируйте файл .conf в AmneziaWG и включите туннель.
    3. Проверьте сайты. Нет соединения? Выключите туннель и скачайте профиль другого сервера.
    Windows Android iPhone / macOS Инструкция AmneziaWG

    Для каждого устройства нужен отдельный профиль: скачивайте его на самом устройстве. Можно сохранить несколько серверов; включайте только один туннель одновременно. Не публикуйте файл — внутри ваш приватный ключ.

    Нужен профиль для другого устройства? Нажмите «Создать отдельный профиль» на карточке и передайте его лично. Лимита устройств нет.
