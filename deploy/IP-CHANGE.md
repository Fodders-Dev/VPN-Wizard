# Смена IP VPN-сервера

Для обычной замены адреса у существующей VPN-ноды больше не нужен новый
запуск разработки. Ключи сервера и клиентов должны остаться прежними.

## С компьютера владельца

Открой ярлык **«Сменить IP VPN»** на рабочем столе. Введи страну (`fi` —
Финляндия, `us` — США, `tr` — Турция) и новый публичный IPv4.
Для Финляндии можно просто нажать Enter в первом вопросе.

То же самое из PowerShell в папке проекта:

```powershell
.\Set-VpnServerIp.ps1 fi 185.202.207.126
```

Сначала только проверить доступ, ключи и план, ничего не меняя:

```powershell
.\Set-VpnServerIp.ps1 fi 185.202.207.126 -CheckOnly
```

При повторном запуске с уже установленным IP изменения не повторяются.
В конце должно быть сообщение об успешном завершении. При ошибке окно
останется открытым: не переключай адреса вручную поверх незавершённой операции.

## Что проверяет и обновляет команда

1. Подключается к управляющему серверу через существующий SSH-профиль `rodnya`.
   Если прямой доступ недоступен, использует существующий административный
   маршрут через сервер в США. Системный прокси компьютера не меняется.
2. Проверяет SSH-ключ нового адреса по доверенному ключу прежнего сервера.
3. Сравнивает публичные ключи AWG с сохранёнными зашифрованными профилями,
   а порты — с текущим реестром. Другую машину автоматически не принимает.
4. Сохраняет приватные резервные копии и меняет Endpoint в файлах профилей,
   адрес основной ноды и её альтернативных подключений в общем реестре.
   Порты, ключи, ограничения и приостановленные подключения сохраняются.
5. Перезапускает API выдачи профилей и обновляет снимок состояния серверов.
   Сами AWG-интерфейсы не перезапускаются. Сторож читает IP из того же реестра.

При неудаче инструмент пытается вернуть затронутые файлы и показывает результат
каждого отката. Неуспешный откат не обозначается как успешный.
Бэкапы лежат в `/var/backups/vpn-wizard/` на управляющем сервере и VPN-ноде.

## Уже установленные приложения

После замены адреса заново скачай профиль той же страны с
[сайта VPN](https://82-25-60-19.nip.io/connect/join.html) и импортируй в AmneziaWG.
В том же браузере выдаётся прежний ключ с актуальным Endpoint. Можно вместо
переимпорта вручную изменить только IP в строке Endpoint, сохранив порт.

Готовый файл внутри приложения не обновляется от изменения реестра на сервере.
Кнопка «Скачать профиль» и QR на сайте уже используют новый адрес.

## Границы механизма

Команда предназначена для VPN-нод `fi/us/tr`. Смена IP нидерландского сервера,
на котором живёт сам сайт, требует отдельного обновления HTTPS, URL сайта
и настроек BotFather. Переустановка сервера с потерей старых ключей также
требует восстановления данных, а не замены одного адреса.

На компьютере нужны существующая `.venv` проекта и ключи в `~/.ssh/`;
на управляющем сервере — установленная версия проекта с этим инструментом.
Пароли и приватные ключи в командную строку вводить не нужно.
